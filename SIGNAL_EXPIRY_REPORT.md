# Signal Expiry Report — Phase 22D

**Date:** 2026-06-04  
**Status:** IMPLEMENTED — timeframe-aware expiry now active

---

## Before Phase 22D

| Issue | Impact |
|-------|--------|
| No `CreatedAt` on `strategy.Signal` | Signal age unmeasurable at execution |
| No expiry check before execution | 1m signals could execute 10+ minutes after generation |
| Uniform 45 s parked-signal fallback | Same timeout for 1m and 1h strategies |
| Uniform 45 min position max-age | Over-holds 1m scalps, under-holds 1h trend trades |

---

## After Phase 22D

### Signal Struct Changes
`engine/internal/strategy/interface.go` — `Signal` now carries:
```go
CreatedAt time.Time  // stamped at strategy output collection
Timeframe string     // "tick" | "1m" | "5m" | "15m" | "1h"
```
Stamps are applied in `processStrategyGroup` at the point each strategy's goroutine
returns signals — before aggregation, before any pipeline stage, guaranteeing the age
clock starts at true generation time.

### Expiry Thresholds Implemented
`engine/internal/trading/loop.go` — `signalMaxAge(timeframe)`:

| Timeframe | Max Age | Rationale |
|-----------|---------|-----------|
| tick | 500 ms | Sub-second edge; price moves 5+ bps in 1 s |
| 1m | 90 s | 1.5 candles; signal stale after 2nd candle close |
| 3m | 4 min | Reserved for future 3m strategies |
| 5m | 7 min | Slightly over 1 candle; moderate-speed edge |
| 15m | 20 min | Structure-based; 1+ candle validity window |
| 1h | 75 min | Trend-following; allows for delayed execution |

### Enforcement Point
`processStrategyGroup` — checked **after aggregation, before any execution step**:
```go
signalAge := time.Since(sig.CreatedAt)
if maxAge := signalMaxAge(sig.Timeframe); signalAge > maxAge {
    log.Printf("[STALE SIGNAL] %s dropped: age %v > %s max %v", ...)
    // rejected, never reaches OMS
}
```

### Signal Age at Execution
- Signal age is logged in the final `[✅ TRADE EXECUTED]` line as `Age: <duration>`.
- Any signal reaching execution with age within its window is confirmed fresh.

### Zero-value Guard
Signals generated by strategies that predate Phase 22D (no `CreatedAt` set) receive
`CreatedAt = time.Now()` at the guard, so they execute immediately with age ≈ 0.
This ensures no regression for legacy strategy code.

---

## Expected Impact
- **Tick strategies:** Eliminates execution of signals queued behind earlier processing
  bursts (multi-strategy parallel runs). Any tick signal > 500 ms old is discarded.
- **1m strategies:** Eliminates execution of signals that passed aggregation but waited
  in the execution loop for > 90 s (e.g. due to risk pipeline back-pressure).
- **Higher timeframes:** Bounded window prevents very old candle signals from executing
  in adverse market conditions far from the original signal price.
