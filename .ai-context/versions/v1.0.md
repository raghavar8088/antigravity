# Architecture Version 1.0

## Theme
Baseline multi-market trading platform architecture.

## Shape
- Next.js client/API layer in `client/`.
- Go execution engine in `engine/`.
- Broker and market data adapters for crypto and Indian markets.
- MongoDB/PostgreSQL/Redis/SQLite persistence mix.
- Paper trading, live trading, backtesting, dashboards, and operational runbooks.

## Key Decisions
- Keep broker/exchange logic behind adapter boundaries.
- Keep strategy, risk, OMS, execution, ledger, and reconciliation as separate concepts.
- Use API routes and dashboard hooks as the UI integration boundary.
- Preserve kill switch and risk gate behavior in production paths.

## AI Use
Read this version when asking why the repository is split between client/API, Go engine, broker adapters, and persistence layers.
