# Architecture Version 1.1

## Theme
AI-assisted development optimization and protected trading boundaries.

## Changes Since 1.0
- Added Graphify knowledge graph and scoped graphs for low-token code relationship queries.
- Added Repomix metadata summary for compact repository orientation.
- Added `.cursorignore` and `runtime/` separation to prevent heavy data indexing.
- Added `.ai-context/` documentation, maps, prompts, owners, glossary, business rules, ADRs, and protected modules.
- Added root `package.json` AI workflow scripts.
- Added local pre-commit AI context refresh installer and CI freshness workflow.

## Current AI Workflow
```text
README_FOR_AI
-> system manifest / business rules / glossary
-> Graphify scoped query
-> repo maps
-> exact source file only when needed
```

## Protected Direction
Future AI work should build features inside existing trading boundaries instead of adding more indexing layers. Risk, OMS, execution, ledger, reconciliation, exchange adapters, and kill switch behavior remain protected.
