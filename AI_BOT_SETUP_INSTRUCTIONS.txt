QUICK START (5 MINUTES)
════════════════════════════════════════════════════════════════════════

STEP 1: Get Your Claude API Key (2 min)
───────────────────────────────────────
1. Visit: https://console.anthropic.com/
2. Sign in or create account
3. Go to "API Keys" section
4. Create a new key
5. Copy it: sk-ant-v1-abc123...

STEP 2: Set Your API Key (1 min)
───────────────────────────────────
Windows Command Prompt:
  set ANTHROPIC_API_KEY=sk-ant-v1-your-key

Windows PowerShell:
  $env:ANTHROPIC_API_KEY = "sk-ant-v1-your-key"

Linux/Mac:
  export ANTHROPIC_API_KEY="sk-ant-v1-your-key"

STEP 3: Install Dependencies (2 min)
──────────────────────────────────────
Open Command Prompt/Terminal and run:
  pip install -r requirements.txt

STEP 4: Run the Bot
─────────────────────
Windows:
  python autonomous_ai_bot.py

Linux/Mac:
  python3 autonomous_ai_bot.py

That's it! The bot does everything else automatically.

════════════════════════════════════════════════════════════════════════
WHAT HAPPENS WHEN YOU RUN IT
════════════════════════════════════════════════════════════════════════

1. SCANNING (2 seconds)
   • Finds all Python files in your application
   • Excludes virtual environments

2. ANALYZING (30 seconds - 5 minutes)
   • Sends code to Claude AI
   • Claude analyzes for: quality, security, performance, bugs
   • Generates fix suggestions

3. PLANNING (5 seconds)
   • Creates upgrade strategy
   • Prioritizes issues (High/Medium/Low)

4. FIXING (1-2 minutes)
   • Applies Claude's fixes automatically
   • Creates backups of originals
   • Updates your code

5. REPORTING (5 seconds)
   • Creates detailed analysis report
   • Saves to: AI_BOT_ANALYSIS_REPORT.txt

6. COMPLETE!
   • Review report and changed files
   • Test your application
   • All done!
