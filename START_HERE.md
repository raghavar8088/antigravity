## 🚀 Quick Start (5 Minutes)

### Step 1: Get API Key (2 min)
```
1. Visit: https://console.anthropic.com/
2. Create/copy your API key
3. Keep it safe!
```

### Step 2: Set API Key (1 min)
```bash
# Windows Command Prompt
set ANTHROPIC_API_KEY=sk-ant-v1-your-key-here

# Windows PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-v1-your-key-here"

# Linux/Mac
export ANTHROPIC_API_KEY="sk-ant-v1-your-key-here"
```

### Step 3: Install Dependencies (2 min)
```bash
pip install -r requirements.txt
```

### Step 4: Run the Bot!
```bash
python autonomous_ai_bot.py
```

**That's it!** The bot does everything else automatically.

## 🆘 Troubleshooting

**Problem:** "ANTHROPIC_API_KEY not set"
**Solution:** Set your API key environment variable (Step 2 above)

**Problem:** "ModuleNotFoundError: anthropic"
**Solution:** Run `pip install -r requirements.txt`

**Problem:** Bot is slow
**Solution:** Normal! Can take 10-30+ minutes for thorough analysis

**Problem:** "Could not parse analysis"
**Solution:** Re-run the bot (temporary API issue)

For more help, see **SETUP_GUIDE.md**
