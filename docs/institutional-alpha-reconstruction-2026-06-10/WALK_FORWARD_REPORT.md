## Walk-Forward Protocol Required

### Recommended Protocol for Top 20 Strategies

**Window Structure:**
- Training (in-sample): 90 days
- Testing (out-of-sample): 30 days
- Walk forward: 5 iterations covering 450 days
- Validation period: Oct 2023 – Dec 2024 (available via broker API or data providers)

**Rolling Window:**
- 30-day rolling windows
- Minimum 20 windows
- Strategy must show positive PF in ≥60% of windows

**Acceptance Criteria:**
| Metric | Minimum to Pass |
|:-------|:---------------:|
| OOS Profit Factor | ≥ 1.30 |
| OOS Win Rate | ≥ 45% (at RR ≥ 2:1) |
| OOS Sharpe | ≥ 1.0 |
| OOS Max Drawdown | ≤ 20% |
| PF consistency across windows | ≥ 60% positive windows |
| OOS trade count | ≥ 50 per validation window |

### Strategy Rejection Criteria

A strategy FAILS walk-forward if:
- In-sample PF significantly exceeds OOS PF (overfitting indicator, typically >0.5 PF degradation)
- PF < 1.0 in more than 40% of rolling windows
- Trade count < 10 per OOS window (insufficient sample)
- Maximum consecutive losses > 8 in any OOS window
- Parameter sensitivity: if PF drops >30% when parameters shift ±10%, the strategy is unstable
